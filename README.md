# AquaFresh Water Delivery

A responsive one-page website for AquaFresh, a drinking water delivery business, built as an internship project with plain HTML, CSS and JavaScript.

**Live website:** https://faiqachaudhry.github.io/aquafresh-water-delivery/

## Description

The page shows the AquaFresh brand, a hero section ("Fresh Water Delivered to Your Door") with an Order Now button, a Projects section and a Contact section. The navigation links (Home, Projects, Contact) scroll to each section.

## Folder structure

```
aquafresh-water-delivery/
├── index.html    # page structure
├── style.css     # original design styles
├── fixes.css     # responsive layout and new-section styles
├── script.js     # Order Now button behavior
├── images/       # project images (if used by style.css)
└── README.md
```

## Local setup

1. Download or clone the repository:
   `git clone https://github.com/Faiqachaudhry/aquafresh-water-delivery.git`
2. Open `index.html` in any web browser. No build step or dependencies are needed.
3. Optional local server: `python -m http.server`, then open http://localhost:8000

## Deployment (GitHub Pages)

1. Push the files to the `main` branch of the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
4. Wait a minute or two, then open the live website URL above.
